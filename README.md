Entry for the [make.fun bounty "Everyday Things, Two Lines, Longer Run"](https://make.fun/bounty/u-suga-everyday-things-two-lines-longer-run-f8734479) — a two-line explanation of a traffic jam for a 10-year-old: one vivid sentence built on an analogy, and one sentence on why that analogy works, what it maps and what it leaves out.

## Run

```sh
python3 main.py
```

Writes the two lines to `/output/entry.txt` and prints them to stdout. No network, no dependencies, deterministic.
